# ISO/IEC 13818-7: description from free sources

A description of the parts of ISO/IEC 13818-7 (*Advanced Audio Coding (AAC)*, 2006) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

Raw AAC files and AAC in AVI and in transport streams use ADTS, a header before every frame. ADIF is a single header at the start of a raw file.

## 2. ADTS header

Source: `multimedia-wiki-adts`, a community source (the page links to an implementation, which was not opened). Fields are read most-significant bit first.

| Field | Bits | Meaning |
|---|---|---|
| syncword | 12 | All ones (0xFFF) |
| ID | 1 | 0 for MPEG-4, 1 for MPEG-2 |
| layer | 2 | 0 |
| protection_absent | 1 | 1 when there is no CRC |
| profile | 2 | The MPEG-4 audio object type minus one ([iso-iec-14496-3.md](iso-iec-14496-3.md)) |
| sampling_frequency_index | 4 | As in the AudioSpecificConfig ([iso-iec-14496-3.md](iso-iec-14496-3.md), section 3); 15 is forbidden |
| private_bit | 1 | |
| channel_configuration | 3 | As in the AudioSpecificConfig; 0 means a program configuration element in the frame |
| original_copy, home | 1 each | |
| copyright_identification_bit, copyright_identification_start | 1 each | |
| frame_length | 13 | Length of the frame in bytes, header included |
| adts_buffer_fullness | 11 | 0x7FF for variable bit rate |
| number_of_raw_data_blocks_in_frame | 2 | Number of AAC frames in this ADTS frame, minus one |
| crc_check | 16 | Only when protection_absent is 0 |

The header is 7 bytes without the CRC and 9 bytes with it.

## Gaps

- **ADIF.** No free source of the ADIF header, or of its signature, that is not an implementation's code was found. Until one is approved, ADIF is neither detected nor probed; its detector entry and its pair of Phase 11 need a source before they are scheduled.
