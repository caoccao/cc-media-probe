# ISO/IEC 14496-3: description from free sources

A description of the parts of ISO/IEC 14496-3 (*Coding of audio-visual objects — Part 3: Audio*, 2019) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

The AudioSpecificConfig describes an MPEG-4 audio stream: its object type (AAC profile, SBR, PS and others), sampling rate and channel configuration. Matroska carries it as codec private data, MP4 as the decoder-specific information of the elementary stream descriptor ([iso-iec-14496-1.md](iso-iec-14496-1.md)), FLV as the AAC sequence header, and AVI inside the wave format structure (`microsoft-heaacwaveinfo`). The standard also defines LATM and LOAS, the in-band transport of transport streams.

## 2. AudioSpecificConfig

Sources: `multimedia-wiki-mpeg-4-audio` and `yohhoy-isobmff-notes`, both community sources. Fields are read most-significant bit first, without byte alignment.

| Field | Bits | Meaning |
|---|---|---|
| `audioObjectType` | 5 | The object type; 31 is an escape, after which 6 more bits give the type minus 32 |
| `samplingFrequencyIndex` | 4 | An index into the table of section 3; 15 is an escape |
| `samplingFrequency` | 24 | Only when the index is 15: the rate in hertz |
| `channelConfiguration` | 4 | Section 4; 0 means that a program configuration element defines the channels |

What follows depends on the object type. For the AAC object types 1 to 4, a general audio configuration follows. For the types 5 (SBR) and 29 (PS), the configuration first names the underlying object type and the rate of the extension; the details are a gap (below).

Object types that the deliverables report by name (`multimedia-wiki-mpeg-4-audio`, `yohhoy-isobmff-notes`): 1 AAC Main, 2 AAC LC, 3 AAC SSR, 4 AAC LTP, 5 SBR, 29 PS. Other values are reported as their number.

## 3. Sampling frequency index

Source: `yohhoy-isobmff-notes`, `multimedia-wiki-mpeg-4-audio`.

| Index | Hertz | Index | Hertz |
|---|---|---|---|
| 0 | 96000 | 7 | 22050 |
| 1 | 88200 | 8 | 16000 |
| 2 | 64000 | 9 | 12000 |
| 3 | 48000 | 10 | 11025 |
| 4 | 44100 | 11 | 8000 |
| 5 | 32000 | 12 | 7350 |
| 6 | 24000 | 13, 14 | reserved |

## 4. Channel configuration

Source: `multimedia-wiki-mpeg-4-audio`. 1: one channel (center); 2: two (left, right); 3: three (center, left, right); 4: four (plus a rear center); 5: five (plus left and right surround); 6: six (5.1); 7: eight (7.1). Values 8 to 15 are reported as their number.

## Gaps

- **SBR and PS signaling** inside the AudioSpecificConfig, both the hierarchical form (types 5 and 29 first) and the backward-compatible form (an extension at the end, which `etsi-ts-102005` mentions without its syntax): no free source of the syntax was found. Until one is approved, the extension object type and rate are reported only where the hierarchical form names them in the fields above; a backward-compatible extension is not read.
- **The general audio configuration** that follows for types 1 to 4 (frame length, dependence on core coder, extension flag): not read.
- **LATM and LOAS** (`StreamMuxConfig`, `AudioMuxElement`): `rfc6416` describes their use in RTP but not their syntax. The LOAS and LATM pairs of Phase 10 need a source before that phase.
