# ISO/IEC 14496-14: description from free sources

A description of the parts of ISO/IEC 14496-14 (*MP4 file format*, 2020) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

On top of the ISO base media file format ([iso-iec-14496-12.md](iso-iec-14496-12.md)), the MP4 file format defines the sample entries of MPEG-4 streams and the box that carries their elementary stream descriptor.

## 2. Sample entries and the elementary stream descriptor box

Source: `3gpp-ts-26244`, clause 6 ("MP4AudioSampleEntry", "MP4VisualSampleEntry", "ESDBox"), which restates them for 3GP files.

- `mp4a`: an audio sample entry (reserved bytes, data reference index, channel count, sample size, sample rate) followed by an `esds` box.
- `mp4v`: a visual sample entry (reserved bytes, data reference index, width, height and the fixed fields of a visual sample entry) followed by an `esds` box.
- `mp4s`: a sample entry for other MPEG-4 streams, followed by an `esds` box.
- `esds`: a full box whose payload is one elementary stream descriptor ([iso-iec-14496-1.md](iso-iec-14496-1.md)).

The codes are registered with the MP4 registration authority (`mp4ra-sample-entries`), and the object type of the stream is the `objectTypeIndication` of its decoder configuration descriptor (`mp4ra-oti`).

## Gaps

- The initial object descriptor box (`iods`) is not needed beyond skipping it.
