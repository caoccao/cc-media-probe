# ISO/IEC 14496-14: description from free sources

A description of the parts of ISO/IEC 14496-14 (*MP4 file format*, 2020) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

On top of the ISO base media file format ([iso-iec-14496-12.md](iso-iec-14496-12.md)), the MP4 file format defines the sample entries of MPEG-4 streams and the box that carries their elementary stream descriptor.

## 2. Sample entries and the elementary stream descriptor box

The registered entries distinguish an audio stream (`mp4a`), a visual stream (`mp4v`), and an MPEG-4 Systems stream such as a scene description (`mp4s`). The object type indication in the nested decoder configuration identifies the coding. For example, the combination `mp4a.40.2` identifies AAC LC. The four-character code `mp4a` alone cannot identify an AAC profile. [RFC 6381, section 3.3](https://www.rfc-editor.org/rfc/rfc6381#section-3.3) · [MP4RA sample entries](https://mp4ra.org/registered-types/codecs)

The MP4 `esds` full box carries an [elementary stream descriptor](iso-iec-14496-1.md) after its version and flags. 3GPP TS 26.244 V19.1.0 clause 6.2 refers the audio entry to MP4. Clause 6.3 shows width, height and the descriptor box in a visual entry. Clause 6.4 is void in this release. The 3GPP tables therefore cannot serve as a general wire layout for all three entries. [3GPP TS 26.244, clauses 6.2–6.4](https://www.etsi.org/deliver/etsi_ts/126200_126299/126244/19.01.00_60/ts_126244v190100p.pdf)

For the corresponding F4V audio entry, Adobe shows the data reference index, channel count, sample size and 16.16 fixed-point sample rate before the child boxes. Channel count and sample size have defaults of 2 and 16 in those tables. Distinguish these sample-entry declarations from the audio object's own configuration. [Adobe F4V, sections 1.8.1 and 2.8.3](https://download.macromedia.com/f4v/video_file_format_spec_v10_1.pdf)

For a stream stored in the MP4 file, its stored `ES_ID` is zero. Dependency and clock-reference flags are clear, a track reference can carry a dependency, and the sync-layer configuration uses predefined value 2. A stream referenced by URL has different URL and sync-layer rules. Reading the stored `ES_ID` as the track identifier loses that distinction. [ISO/IEC 14496-14:2020, clause 4, published preview](https://cdn.standards.iteh.ai/samples/79110/5bc74d630043408db7108caf66772096/ISO-IEC-14496-14-2020.pdf)

## Gaps

- The initial object descriptor box (`iods`) is outside the requested metadata. The cited 3GPP visual table does not establish the layout of an arbitrary MPEG-4 Systems sample entry.
