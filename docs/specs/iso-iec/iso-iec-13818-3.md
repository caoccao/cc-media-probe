# ISO/IEC 13818-3: description from free sources

A description of the parts of ISO/IEC 13818-3 (*MPEG-2 audio*, 1998) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

ISO/IEC 13818-3 covers two distinct extensions. Its low-sampling-frequency mode uses half the MPEG-1 sampling rates. Its backward-compatible multichannel mode adds channels to an MPEG-1-compatible signal. The two-bit version notation used by the community frame-header reference gives low-sampling-frequency MPEG-2 the value 2. The value 0 denotes the separate, non-ISO extension commonly called MPEG 2.5. [ISO/IEC 13818-3](https://www.iso.org/standard/26797.html)

## 2. Frame header

For low-sampling-frequency MPEG-2, the rate index selects 22050, 24000 or 16000 Hz. Read the MPEG-2 column for the indicated layer in the [frame header and bitrate tables](iso-iec-11172-3.md). For MPEG 2.5 the corresponding rates are 11025, 12000 and 8000 Hz (`mp3-tech-frame-header`).

A low-sampling-frequency MPEG-2 Layer III frame covers **576 samples per channel**. For an indexed bitrate, its byte length is `floor(72 × bitrate / sampling_rate) + padding`, with bitrate in bits per second, rate in hertz and padding in bytes. The factor 72 follows from 576 samples divided by eight bits per byte. A verified count of such frames at a constant sampling rate gives coded duration as `frame_count × 576 / sampling_rate`. [ISO/IEC 14496-3:2001/Amd.3, Layer III frame definition](https://cdn.standards.iteh.ai/samples/39584/696c43b397e24f5ea9b6f80f8b193464/ISO-IEC-14496-3-2001-Amd-3-2005.pdf)

## Gaps

- The ISO sample count above applies to MPEG-2. The community reference documents MPEG 2.5 header rates, but does not independently establish its Layer III frame duration.
- The project reads the channel mode of the compatible signal. A multichannel extension can carry additional channels, so the core channel count alone cannot establish the total.
