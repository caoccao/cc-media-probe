# ISO/IEC 13818-3: description from free sources

A description of the parts of ISO/IEC 13818-3 (*MPEG-2 audio*, 1998) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

MPEG-2 audio extends the MPEG-1 frame header of [iso-iec-11172-3.md](iso-iec-11172-3.md) to half the sampling rates, with their own bit rate table. The header layout is the same; the version field is 2. The "MPEG 2.5" extension, with version 0, quarters the rates; the source describes it as a later extension of MPEG-2, and it is read the same way.

## 2. Frame header

As in [iso-iec-11172-3.md](iso-iec-11172-3.md), section 2, with the MPEG-2 columns of its sections 3 and 4 (`mp3-tech-frame-header`): 22050, 24000 and 16000 Hz, and the MPEG-2 bit rates.

## Gaps

- **Samples per frame.** No free source states the number of samples of an MPEG-2 layer III frame. Until one is approved, durations of MPEG-2 and MPEG 2.5 layer III streams are not computed from frame counts.
- The multichannel extension of MPEG-2 audio, carried after the MPEG-1 compatible data, is not read; such a stream is reported with its MPEG-1 compatible channels.
