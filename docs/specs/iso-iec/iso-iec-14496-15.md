# ISO/IEC 14496-15: description from free sources

A description of the parts of ISO/IEC 14496-15 (*carriage of NAL-unit structured video in the ISO base media file format*, 2024) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

The standard defines the decoder configuration records of AVC, HEVC and VVC, which an MP4 sample entry carries in its `avcC`, `hvcC` and `vvcC` box, and which Matroska and FLV carry unchanged as codec private data and sequence headers (`ietf-draft-cellar-codec`, `adobe-flv-f4v-10-1`). It also defines the length-prefixed form of the samples. The parameter sets inside a record are the NAL units of the video standards, which are free: ITU-T H.264, H.265 and H.266 (`itu-t-h-264`, `itu-t-h-265`, `itu-t-h-266`).

## 2. AVC decoder configuration record

Source: `yohhoy-isobmff-notes` (a developer's notes of the syntax, a community source). Apple's documentation of the `avcC` atom (`apple-quicktime-file-format`, "AVC decoder configuration atom") confirms that the atom holds this record and that the record is the one of ISO/IEC 14496-15. The record is byte-aligned; fields are big-endian.

| Field | Bits | Meaning |
|---|---|---|
| `configurationVersion` | 8 | 1 |
| `AVCProfileIndication` | 8 | `profile_idc` of the sequence parameter sets |
| `profile_compatibility` | 8 | The byte between `profile_idc` and `level_idc` of the sequence parameter sets: the constraint flags |
| `AVCLevelIndication` | 8 | `level_idc` of the sequence parameter sets |
| reserved | 6 | All ones |
| `lengthSizeMinusOne` | 2 | Size in bytes of the length field before each NAL unit of a sample, minus one; 0, 1 or 3 |
| reserved | 3 | All ones |
| `numOfSequenceParameterSets` | 5 | Number of sequence parameter sets that follow |
| `sequenceParameterSetLength`, `sequenceParameterSetNALUnit` | 16, then that many bytes | Each sequence parameter set, a complete NAL unit |
| `numOfPictureParameterSets` | 8 | Number of picture parameter sets that follow |
| `pictureParameterSetLength`, `pictureParameterSetNALUnit` | 16, then that many bytes | Each picture parameter set |

When `AVCProfileIndication` is 100, 110, 122 or 144, the record continues with: 6 reserved bits (ones), `chroma_format` (2), 5 reserved bits (ones), `bit_depth_luma_minus8` (3), 5 reserved bits (ones), `bit_depth_chroma_minus8` (3), `numOfSequenceParameterSetExt` (8), and that many sequence parameter set extensions, each with a 16-bit length. Records written by older software may end before this part; the parameters are then taken from the sequence parameter set itself.

## 3. HEVC decoder configuration record

Source: `yohhoy-isobmff-notes`. Big-endian, byte-aligned.

| Field | Bits | Meaning |
|---|---|---|
| `configurationVersion` | 8 | 1 |
| `general_profile_space` | 2 | As in the profile-tier-level structure of ITU-T H.265 |
| `general_tier_flag` | 1 | As in H.265 |
| `general_profile_idc` | 5 | As in H.265 |
| `general_profile_compatibility_flags` | 32 | As in H.265 |
| `general_constraint_indicator_flags` | 48 | As in H.265 |
| `general_level_idc` | 8 | As in H.265 |
| reserved | 4 | All ones |
| `min_spatial_segmentation_idc` | 12 | |
| reserved | 6 | All ones |
| `parallelismType` | 2 | |
| reserved | 6 | All ones |
| `chromaFormat` | 2 | `chroma_format_idc` |
| reserved | 5 | All ones |
| `bitDepthLumaMinus8` | 3 | |
| reserved | 5 | All ones |
| `bitDepthChromaMinus8` | 3 | |
| `avgFrameRate` | 16 | |
| `constantFrameRate` | 2 | |
| `numTemporalLayers` | 3 | |
| `temporalIdNested` | 1 | |
| `lengthSizeMinusOne` | 2 | As in section 2 |
| `numOfArrays` | 8 | Number of arrays of NAL units that follow |

Each array: `array_completeness` (1), a reserved bit (0), `NAL_unit_type` (6), `numNalus` (16), then `numNalus` NAL units, each with a 16-bit `nalUnitLength`. The arrays hold the video, sequence and picture parameter sets, and SEI messages.

## 4. Length-prefixed samples

A sample of an `avc1`, `avc3`, `hvc1`, `hev1`, `vvc1` or `vvi1` track, and a Matroska frame of the same codecs, is a sequence of NAL units, each preceded by its length in `lengthSizeMinusOne + 1` bytes, big-endian, with no start codes (`yohhoy-isobmff-notes`; `ietf-draft-cellar-codec`, the AVC and HEVC mappings). The sample entry codes and their meaning, parameter sets only in the sample entry or also in the samples, are registered with the MP4 registration authority (`mp4ra-sample-entries`).

## Gaps

- **VVC.** No free source of the VVC decoder configuration record that is not an implementation's code was found. Until one is approved, a VVC record is not parsed: the parameter sets of a VVC stream are read from the samples where they appear in band (ITU-T H.266), and otherwise the stream keeps its container-declared values.
- **Further structures of the standard** (sample groups, extractors, the layered and multi-view records) are not needed by the deliverables.
