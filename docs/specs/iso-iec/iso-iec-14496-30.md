# ISO/IEC 14496-30: description from free sources

A description of the parts of ISO/IEC 14496-30 (*timed text and other visual overlays in ISO base media file format*, 2018) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

The deliverables need two things from this standard: the WebVTT header text that an MP4 track carries (plan section 4.3, "WebVTT: header text carried by the container"), and the identification of TTML tracks.

## 2. WebVTT sample entry

The registered `wvtt` sample entry contains a required `vttC` configuration box. The amended entry also allows a source label (`vlab`, recommended) and a bitrate box (`btrt`, optional). Locate the configuration by child box type within the entry. The source label distinguishes cues originating in different movies. [2022 amendment, clause 6.5](iso-iec-14496-30-amd-1.md) · [W3C Breakouts Day 2025 presentation](https://ntrrgc.github.io/w3c-breakouts-2025-mse-text-tracks/)

The configuration is a regular box carrying a UTF-8 `boxstring`. Read the payload through the end of the box. There is no length prefix, version/flags word or terminating NUL to strip. The text contains the WebVTT signature and file-header lines. A separate style block or cue occurring later in a standalone file is outside that header. Cue data lives in media samples (`vttc` for a cue and `vtte` for an empty interval). [MPEG meeting contribution, WebVTT configuration box](https://biblio.telecom-paristech.fr/cgi-bin/download.cgi?id=13809) · [Published conformance criteria for clauses 6.1 and 6.5](https://validator.unified-streaming.com/docs/available_suites/timed-text-recommendations.html) · [W3C WebVTT file structure](https://www.w3.org/TR/webvtt1/)

## 3. TTML

The registered `stpp` sample entry identifies XML subtitles. Other XML subtitle formats can use the same entry. Check the entry's namespace field for the TTML namespace `http://www.w3.org/ns/ttml` before reporting TTML. The CMAF IMSC1 text profile explicitly uses that value. If the field is truncated, absent or unrecognized, only the generic XML subtitle declaration is established. The namespace alone cannot identify a particular TTML profile. [MP4RA sample entries](https://mp4ra.org/registered-types/codecs) · [W3C TTML2 namespaces](https://www.w3.org/TR/ttml2/#namespaces) · [CMAF subtitle profiles, clause 11.3.2](https://cdn.standards.iteh.ai/samples/74442/8c1690763bcd4a809c3737ff64ff12ff/ISO-IEC-23000-19-2018-Amd-2-2019.pdf)

## Gaps

- The presentation illustrates the WebVTT boxes. The separate meeting contribution and conformance criteria provide the wire-format evidence proposed for G1.6. A malformed header cannot be repaired by deleting a trailing byte.
- Identifying the TTML namespace is in scope. Resolving individual TTML profiles, interpreting auxiliary resource MIME types, and reading subtitle documents or cue timing are outside the current deliverables.
