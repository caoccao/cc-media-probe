# ISO/IEC 23003-5: description from free sources

A description of the parts of ISO/IEC 23003-5 (*uncompressed audio in MPEG-4 file format*, 2020) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

The sample entries `ipcm` (integer PCM) and `fpcm` (floating-point PCM) of an MP4 file carry a PCM configuration box, `pcmC`, which gives the byte order and the sample size. The codes are registered with the MP4 registration authority (`mp4ra-sample-entries`).

## 2. PCM configuration box

Source: `iteh-iso-iec-23003-5-preview`, a free preview of the standard that a standards reseller publishes; it holds this clause in full.

The box is a full box with version 0 and flags 0 ([iso-iec-14496-12.md](iso-iec-14496-12.md), section 2), with exactly one `pcmC` required in each `ipcm` or `fpcm` entry.

| Field | Bits | Meaning |
|---|---|---|
| `format_flags` | 8 | Bit 0x01: little-endian samples; otherwise big-endian. Other bits are reserved and zero |
| `PCM_sample_size` | 8 | Bits per sample: 16, 24 or 32 for integers; 32 or 64 for floating point |

Integer samples use two’s complement. Floating-point samples follow IEEE 754, with full scale at magnitude 1.0. One track sample is a PCM frame containing one value per channel at the same instant, packed without gaps. The channel count can be specified in the audio sample entry or its channel layout box (`chnl`). The layout box is mandatory for multichannel PCM and establishes channel order when present. [ISO/IEC 23003-5:2020, clauses 5.1.1–5.1.3](https://cdn.standards.iteh.ai/samples/77752/a17f98e0bb664a939b031b6a969995d9/ISO-IEC-23003-5-2020.pdf)

## Gaps

- The preview refers to the base format for the syntax of `chnl`. If the channel count requires an unparsed layout box, leave it unresolved. A channel count alone does not identify speaker positions.
