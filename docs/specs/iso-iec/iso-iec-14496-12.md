# ISO/IEC 14496-12: description from free sources

A description of the parts of ISO/IEC 14496-12 (*ISO base media file format*, 2026) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

MP4, 3GP, 3G2 and F4V are built on the ISO base media file format, which descends from the QuickTime file format. Most of the boxes that the prober reads have the same layout as the QuickTime atoms of the same name, which Apple's documentation describes field by field (`apple-quicktime-file-format`, a normative source for MOV). This description maps each box to that documentation, and to the free 3GPP and W3C documents for what QuickTime does not have.

## 2. Box structure

Source: `apple-quicktime-file-format` ("Atoms"), `3gpp-ts-26244` (clause 6.2).

| Field | Bits | Meaning |
|---|---|---|
| `size` | 32 | Size of the box in bytes, header included; 1 means that a 64-bit `largesize` follows the type; 0 means that the box extends to the end of the file |
| `type` | 32 | Four characters; `uuid` means that a 16-byte extended type follows |
| `largesize` | 64 | Only when `size` is 1 |

A *full box* continues with an 8-bit `version` and 24-bit `flags`; a version of 1 selects 64-bit times and durations where a box has them (`apple-quicktime-file-format`, the movie, track and media headers; `3gpp-ts-26244`, the segment index and decode-time boxes).

## 3. Boxes and their sources

| Box | What the prober reads | Source |
|---|---|---|
| `ftyp` | Major brand, minor version, compatible brands | `apple-quicktime-file-format` ("File type compatibility atom"); brands in `mp4ra-brands` |
| `moov`, `trak`, `mdia`, `minf`, `stbl`, `edts`, `udta` | Containers | `apple-quicktime-file-format` |
| `mvhd` | Time scale, duration | `apple-quicktime-file-format` ("Movie header atom") |
| `tkhd` | Track ID, flags, duration, presentation width and height | `apple-quicktime-file-format` ("Track header atom") |
| `elst` | Edit list entries | `apple-quicktime-file-format` ("Edit list atom") |
| `mdhd` | Time scale, duration, language | `apple-quicktime-file-format` ("Media header atom"). In ISO base media the language is three 5-bit letters, each the letter minus 0x60, packed after a zero bit, giving an ISO 639-2 code (`loc-iso-639-2`) |
| `hdlr` | Handler type (`vide`, `soun`, `text`, `subt`, `meta` and others) | `apple-quicktime-file-format` ("Handler reference atom"); handlers in `mp4ra-handlers` |
| `stsd` | Sample entries: the visual and audio sample entry fields and their configuration boxes | `apple-quicktime-file-format` ("Sample description atom"); `3gpp-ts-26244` (clauses 6.2 and 6.4); codes in `mp4ra-sample-entries` |
| `stts`, `ctts`, `stsc`, `stsz`, `stco`, `co64`, `stss` | Sample timing, composition offsets, chunking, sizes, offsets, sync samples | `apple-quicktime-file-format` (the atoms of the same names) |
| `colr`, `pasp`, `clap` | Color description, pixel aspect ratio, clean aperture | `apple-quicktime-file-format`; the `nclx` code points in `itu-t-h-273` |
| `sidx` | Segment index | `3gpp-ts-26244` (the segment index box) |
| `tfdt` | Decode time of a track fragment | `3gpp-ts-26244` (the track fragment base media decode time box) |

## Gaps

- **Movie fragments** other than `sidx` and `tfdt`: the movie extends box (`mvex`, `mehd`, `trex`), the movie fragment (`moof`, `mfhd`), the track fragment (`traf`, `tfhd`, `trun`) and the fragment random access boxes (`mfra`, `tfra`, `mfro`). No free source of their syntax that is not an implementation's code was found. ISO's free 2015 edition of this standard, from its list of publicly available standards (`iso-publicly-available-standards`), defines them; it is served only to a browser after a license page, so it can be placed by hand. Until a source is approved, fragmented MP4 is probed only through the boxes above, and its durations and sample counts are not derived from fragments.
- **Item-based files** (`meta` with `iloc`, `iinf`) are not needed by the deliverables.
