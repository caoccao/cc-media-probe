# ISO/IEC 11172-1: description from free sources

A description of the parts of ISO/IEC 11172-1 (*MPEG-1 systems*, 1993) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

MPEG-1 program streams (`mpg` files of the MPEG-1 era) differ from MPEG-2 program streams in their pack header. The prober must tell the two apart and read the system clock reference and the stream identifiers of the packets.

## 2. What the free sources establish

ITU-T H.222.0, the MPEG-2 systems standard, is free (`itu-t-h-222-0`, with its amendment `itu-t-h-222-0-amd-1`). It defines the MPEG-2 program stream: the pack header, whose start code 0x000001BA is followed by the bits `01` (table 2-39), the system header, and the packets with their stream identifiers. It also names the stream identifiers and PES fields that carry ISO/IEC 11172-1 streams (section 2.4.3.7, the `MPEG1_MPEG2_identifier` and `original_stuff_length` fields), which tells that MPEG-1 packets share the stream identifiers.

## Gaps

- **The MPEG-1 pack header** after its start code: no free source was found. Until one is approved, a pack header that does not continue with `01` is reported as not MPEG-2, the stream is probed only through the packets that follow, by their stream identifiers, and its system clock reference is not read.
