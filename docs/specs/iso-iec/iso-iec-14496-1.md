# ISO/IEC 14496-1: description from free sources

A description of the parts of ISO/IEC 14496-1 (*Coding of audio-visual objects — Part 1: Systems*, 2026) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

MP4 files carry the configuration of MPEG-4 audio and visual streams, and of several others, in an elementary stream descriptor inside the `esds` box of the sample entry (see [iso-iec-14496-14.md](iso-iec-14496-14.md)). Transport streams can carry the same descriptors. The project reads the elementary stream descriptor, the decoder configuration descriptor inside it, and the decoder-specific information inside that, which holds the codec's own configuration: an AudioSpecificConfig for AAC ([iso-iec-14496-3.md](iso-iec-14496-3.md)), the visual object sequence for MPEG-4 Visual ([iso-iec-14496-2.md](iso-iec-14496-2.md)).

## 2. Descriptors

Every descriptor starts with an 8-bit tag and a size, then its fields (`etsi-ts-102428`, annex A). The tags used here:

| Tag | Descriptor |
|---|---|
| 0x02 | Initial object descriptor |
| 0x03 | Elementary stream descriptor (`ES_Descriptor`) |
| 0x04 | Decoder configuration descriptor (`DecoderConfigDescriptor`) |
| 0x05 | Decoder-specific information (`DecoderSpecificInfo`) |
| 0x06 | Sync layer configuration descriptor (`SLConfigDescriptor`) |

The size counts payload bytes after the tag and the size field. Each byte contributes seven bits, most significant group first. A set high bit signals another size byte. The descriptor payload limit is 28 bits. Bound the read to four size bytes and the enclosing descriptor or box before reading any children. The ETSI examples show one-byte sizes. The general encoding is defined in the earlier Systems edition, clauses 7.2.2.2 and 8.3.3. [ISO/IEC 14496-1:2010](https://www.iso.org/standard/55688.html) · [ETSI TS 102 428, annex A](https://www.etsi.org/deliver/etsi_ts/102400_102499/102428/01.02.01_60/ts_102428v010201p.pdf)

## 3. Elementary stream descriptor

The ETSI examples illustrate the header and the clock-reference field. The general optional fields are defined in ISO/IEC 14496-1, `ES_Descriptor`.

| Field | Bits | Meaning |
|---|---|---|
| tag | 8 | 0x03 |
| size | see section 2 | |
| `ES_ID` | 16 | |
| `streamDependenceFlag` | 1 | When set, a 16-bit `dependsOn_ES_ID` follows the flags |
| `URL_Flag` | 1 | When set, an 8-bit URL length and the URL follow |
| `OCRstreamFlag` | 1 | When set, a 16-bit `OCR_ES_Id` follows |
| `streamPriority` | 5 | |

The optional dependency, URL and clock-reference fields follow the flags and priority in that order. The URL length counts bytes. ETSI illustrates a clock reference in the video descriptor and uses a subset of the possible flag combinations. See the [MP4 file rules](iso-iec-14496-14.md) for restrictions on a stored descriptor.

## 4. Decoder configuration descriptor

The field layout is illustrated in `etsi-ts-102428`, annex A and tables 2 and 3. The bitrate definitions are in ISO/IEC 14496-1:2010, clause 7.2.6.6.

| Field | Bits | Meaning |
|---|---|---|
| tag | 8 | 0x04 |
| size | see section 2 | |
| `objectTypeIndication` | 8 | The codec; the values are registered with the MP4 registration authority (`mp4ra-oti`). For example 0x40 is MPEG-4 Audio, 0x20 MPEG-4 Visual, 0x21 AVC. |
| `streamType` | 6 | 0x04 visual, 0x05 audio; the others are listed in `etsi-ts-102428`, table 3, and `mp4ra-stream-types` |
| `upStream` | 1 | |
| reserved | 1 | 1 |
| `bufferSizeDB` | 24 | Decoding buffer size, bytes |
| `maxBitrate` | 32 | Maximum bitrate over a one-second window, in bits per second |
| `avgBitrate` | 32 | Declared average in bits per second. The earlier Systems edition specifies zero for variable-bitrate streams |

When present, the nested decoder-specific information (tag 0x05) carries codec-defined bytes. Interpret them using the object type and the descriptor’s payload length.

## Gaps

- The cited ETSI tables do not exercise multi-byte sizes or every optional flag. The historical Systems reference explains the general encoding. Edition-specific additions in 2026 require separate evidence.
- Object and initial object descriptors, scene description and the sync layer are not needed beyond skipping them.
