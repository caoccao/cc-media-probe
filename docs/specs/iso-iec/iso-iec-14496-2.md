# ISO/IEC 14496-2: description from free sources

A description of the parts of ISO/IEC 14496-2 (*Coding of audio-visual objects — Part 2: Visual*, 2004) that the deliverables need, written for this project from free sources ([README](README.md)). It is not the standard.

## 1. Scope

The deliverables of plan section 4.3 parse the visual object sequence and video object layer headers of MPEG-4 Visual streams: profile and level, dimensions, pixel aspect ratio, frame rate and scan type. They appear in Matroska frames, as MP4 decoder-specific information ([iso-iec-14496-1.md](iso-iec-14496-1.md)), in AVI chunks, in transport and program streams, and in raw files.

## 2. What the free sources establish

- The object type indication of MPEG-4 Visual in an elementary stream descriptor is 0x20, and its sample entry code is `mp4v` (`mp4ra-oti`, `mp4ra-sample-entries`).
- Matroska carries the stream under its own codec identifiers (`ietf-draft-cellar-codec`), and AVI under four-character codes (`microsoft-fourcc-codes`, `rfc2361`).

## Gaps

- **The headers themselves.** Every description of the visual object sequence and video object layer header that was found is an implementation's code, the generated documentation of one, or a patent. None is used (plan section 1.3). Until a source is approved, MPEG-4 Visual streams are identified, with container-declared values only: the MPEG-4 Visual pairs of plan section 4.3 are deferred, and the raw MPEG-4 Visual elementary stream is detected only where a container or a file name says so.
