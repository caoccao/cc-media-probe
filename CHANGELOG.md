# Changelog

All notable changes to the published crates, `cc-media-probe` and `cc-media-probe-cli`, are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html). Besides the six kinds of change of that format, a release can list **Changed output**: every change in what a probe reports for the same input, such as a field that is now filled or a value that is now read differently. Each entry is added in the commit that makes the change.
